# On-disk formats

All integers are little-endian unless stated otherwise. "Varint" is the
LEB128-style 7-bits-per-byte variable-length encoding, low group first. A
"length-prefixed slice" is `varint(len)` followed by `len` bytes.

## Internal key

```
internal_key := user_key (N bytes) || trailer (8 bytes, fixed64 LE)
trailer      := (sequence << 8) | value_type
value_type   := 0x00 (deletion) | 0x01 (value)
```

Sequence numbers occupy the high 56 bits; the maximum is `2^56 - 1`. Ordering:
user key ascending, then trailer so that a larger sequence number sorts first for
a shared user key.

## Write batch (also the WAL payload)

```
batch  := header record*
header := sequence (fixed64) count (fixed32)
record := kValue    (0x01) key(lp) value(lp)
        | kDeletion (0x00) key(lp)
```

The first record is assigned the header's `sequence`; the i-th record gets
`sequence + i`.

## Write-ahead log framing

The log is a sequence of 32 KiB blocks. Each block holds one or more physical
records:

```
record := checksum (fixed32) length (fixed16) type (u8) data[length]
type   := 1 FULL | 2 FIRST | 3 MIDDLE | 4 LAST
```

`checksum` is the masked CRC32C of `type ++ data`. A logical record too large for
the remainder of a block is split into `FIRST`/`MIDDLE`/`LAST` fragments; when
fewer than 7 bytes remain in a block they are zero-padded and the next record
starts in a new block.

## SSTable

```
file := data_block* filter_block metaindex_block index_block footer
```

### Block

```
block   := entry* restart[num_restarts] (fixed32) num_restarts (fixed32)
entry   := varint(shared) varint(non_shared) varint(value_len)
           key_delta[non_shared] value[value_len]
```

Each entry stores only the bytes of its key that differ from the previous key
(`shared` gives the shared prefix length). Every `block_restart_interval` entries
the prefix resets to zero — a *restart point* whose byte offset is listed in the
trailing restart array. Readers binary-search the restart array, then scan.

### Block trailer (in the file)

Immediately after each block's bytes:

```
trailer := compression_type (u8) crc32c (fixed32, masked)
```

`crc32c` covers the *stored* block contents (after any compression) plus the
compression byte. `compression_type` is one of:

| value | codec | status |
|---|---|---|
| `0` | none | stored verbatim |
| `1` | snappy | reserved (recognised on read, never emitted) |
| `2` | zstd | reserved (recognised on read, never emitted) |
| `3` | rle | run-length, see below |
| `4` | lz | LZ77, see below |

A block is only stored under a compressing codec when that codec shrinks it;
otherwise it falls back to `0`, so the tag always names the codec actually
applied and a reader never has to trust that compression helped.

### Compression codecs

Both codecs are byte streams the reader bounds against a fixed maximum
decompressed size; the uncompressed length is *not* stored in the block.

**RLE (`3`)** — a sequence of runs:

```
run    := header payload
header := varint( (count << 1) | kind )   ; count >= 1
kind=0 (literal): count raw bytes follow, emitted verbatim
kind=1 (repeat):  one byte follows, emitted count times
```

**LZ (`4`)** — a sequence of tokens:

```
literal := varint(len << 1 | 0)                 len raw bytes
match   := varint((len - 4) << 1 | 1) varint(distance)
```

A match copies `len` bytes from `distance` bytes before the current output
position (`distance` one-based); the copy is defined byte-by-byte, so an
overlapping match (`distance < len`) repeats a short pattern. `distance` is bounded
by the 64 KiB window and validated against the bytes produced so far.

### Block handle

```
handle := varint(offset) varint(size)
```

`size` is the block content length, excluding the 5-byte trailer.

### Filter block

```
filter_block := filter* offset[num_filters] (fixed32)
                offset_array_start (fixed32) base_lg (u8)
```

One filter covers each `2^base_lg` bytes (`base_lg = 11`, i.e. 2 KiB) of data
output. `offset[i]` locates the i-th filter; `key_may_match(block_offset, key)`
selects the filter by `block_offset >> base_lg`.

### Bloom filter payload

`bits_per_key * n` bits (rounded to bytes, minimum 64 bits), followed by a single
byte recording the number of probes `k`. Probe positions are generated by double
hashing from one base hash.

### Metaindex block

An ordinary block whose entries map meta-block names to handles. The filter entry
is keyed `filter.<policy-name>`.

### Index block

An ordinary block whose entries map each data block's maximum key to that block's
handle (encoded as the entry value).

### Footer (48 bytes)

```
footer := metaindex_handle index_handle padding magic (fixed64)
```

The two handles are written first and the region is zero-padded to 40 bytes; the
final 8 bytes are the table magic number.

## MANIFEST (`VersionEdit`)

Each MANIFEST record is a `VersionEdit`: a flat sequence of tagged fields.

```
field := tag (varint) payload
```

| tag | field | payload |
|---|---|---|
| 1 | comparator | name (lp) |
| 2 | log number | varint64 |
| 3 | next file number | varint64 |
| 4 | last sequence | varint64 |
| 5 | compact pointer | level (varint) key (lp) |
| 6 | deleted file | level (varint) number (varint64) |
| 7 | new file | level (varint) number (varint64) size (varint64) smallest (lp) largest (lp) |
| 9 | previous log number | varint64 |

Replaying the MANIFEST applies each edit in order to reconstruct the current
version's per-level file lists.

## Archive (logical backup)

An archive is a single self-describing byte string capturing a set of key/value
records, independent of the SSTable layout.

```
archive := header body_len (fixed32) stored_body crc32c (fixed32, masked)
header  := magic (8 bytes = "LGNARCH1") version (fixed32) flags (fixed32)
```

`crc32c` is the masked CRC32C over every byte before it (header through
`stored_body`). `stored_body` is the record stream below, LZ-compressed when the
`flags` `COMPRESSED` bit (`0x1`) is set. The record stream is:

```
record* := ( PUT    (0x01) key(lp) value(lp)
           | DELETE (0x02) key(lp) )*
           END (0x00) varint(record_count)
```

The trailing `record_count` must equal the number of records decoded, and no
bytes may follow the `END` marker. `version` is `1`; a reader rejects other
versions rather than guessing.
